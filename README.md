mend is one command-line patch tool for every AI edit format: it applies unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches, and JSON tool calls to a tree of files, all or nothing. It finds the lines each edit names at the first of three matching tiers, re-indents at the loosest tier, and never writes a partial patch.

## Run it

```sh
node main.ts [options] [PATCH]
```
